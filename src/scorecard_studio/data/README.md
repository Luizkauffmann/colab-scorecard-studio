# credit_risk_dataset.csv.gz

Kaggle "Credit Risk Dataset" by laotse: https://www.kaggle.com/datasets/laotse/credit-risk-dataset

- Unmodified copy of `credit_risk_dataset.csv` as downloaded from Kaggle (gzip-compressed).
- 32,581 rows x 12 columns. Target `loan_status` (1 = default).
- SHA-256 of the uncompressed CSV: `ce3c6d2167717bf1627d1c0c81cbccd28323cd4aa7b96d542599366d5ff6aac8`
- The dataset simulates credit bureau data. Use it to learn the workflow, not to draw
  conclusions about real lending.

Load it with `scorecard_studio.load_credit_risk_dataset()`.
